Process management commands control the maliang background process. These commands are only available in the terminal.

## start

Start the maliang service. Runs as a background daemon by default and automatically tails logs.

```bash
maliang start
```

**Options:**

| Option | Description |
| --- | --- |
| `-f`, `--foreground` | Run in foreground, not as a background daemon |
| `--no-logs` | Don't tail logs after starting |

## stop

Stop the running maliang service.

```bash
maliang stop
```

## restart

Restart the maliang service (stop then start).

```bash
maliang restart
```

**Options:**

| Option | Description |
| --- | --- |
| `--no-logs` | Don't tail logs after restart |

## update

Update code and restart the service. Automatically performs:

1. Pull latest code (`git pull`)
2. Stop current service
3. Update Python dependencies
4. Reinstall CLI
5. Start service

```bash
maliang update
```

<Warning>
  If `git pull` fails (e.g., uncommitted local changes), the update aborts and the service remains unaffected.
</Warning>

## status

Check maliang service status, including process info, version, and current model/channel configuration.

```bash
maliang status
```

## logs

View service logs.

```bash
maliang logs
```

**Options:**

| Option | Description | Default |
| --- | --- | --- |
| `-f`, `--follow` | Continuously tail log output | No |
| `-n`, `--lines` | Show last N lines | 50 |

Examples:

```bash
# View last 100 lines
maliang logs -n 100

# Continuously tail logs
maliang logs -f
```

## install-browser

Install Playwright and Chromium browser for the [browser tool](/tools/browser).

```bash
maliang install-browser
```

<Tip>
  Only needed when using browser tools (web browsing, screenshots, etc.).
</Tip>

## run.sh Compatibility

If Cow CLI is not installed, you can use `run.sh` to manage the service:

| maliang command | run.sh equivalent |
| --- | --- |
| `maliang start` | `./run.sh start` |
| `maliang stop` | `./run.sh stop` |
| `maliang restart` | `./run.sh restart` |
| `maliang update` | `./run.sh update` |
| `maliang status` | `./run.sh status` |
| `maliang logs` | `./run.sh logs` |

<Note>
  The `maliang` command is recommended — it provides cleaner syntax and richer features. It is automatically installed via the one-click install script.
</Note>
