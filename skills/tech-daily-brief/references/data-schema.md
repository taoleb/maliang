# data.json 数据契约（data-schema.md v2.1）

`scripts/build_daily.py` 把 data.json 注入模板的 `<script id="tdb-data">` 数据槽。
**只写 JSON，不碰模板结构**。构建脚本会自动校验以下硬规则，不达标直接拒绝生成：

- **板块数量灵活**：4-8 个自选板块（方向可借鉴 6606 周情报库类目池：人工智能/机器人/通信/半导体/安全/能源/飞行汽车，或按当日热点自定），每板块 2-6 条，总条数 ≥16
- 每条 NEWS 必须有 http(s) 原文链接、【上车机会点】、信源、评级
- 每条观点必须具名大牛 + 原文链接
- 【日期铁律】date 必须等于系统今天、source_date 必须等于昨天（归档加 `--allow-past`）
- weekly 七日全景（推荐）：days 覆盖 5-9 天且按日期升序，每日精选条目必须带原文

## 顶层字段

```json
{
  "date": "2026-08-27",
  "weekday": "周四",
  "source_date": "2026-08-26",
  "src_chips": ["联网搜索核实", "逐条附原文", "信源日=前一日"],
  "stats": {"today": 24, "week": 295, "experts": 6, "topics": 5, "peak": "人工智能"},
  "modules": [...],
  "news": [...],
  "insights": [...],
  "radar": [...],
  "ops": [...],
  "versus": {...},
  "techs": [...],
  "topics": [...],
  "weekly": {...}
}
```

## modules（板块定义：4-8 个自选，顺序即展示顺序）

板块不是固定 6 个——按当日素材实际分布自选 4-8 个，方向可借鉴 6606 周情报库类目池。每个板块颜色自定：

```json
{"key": "headline",  "name": "今日头条",     "color": "#e5484d"},
{"key": "frontier",  "name": "科技前沿",     "color": "#2f6fed"},
{"key": "basic",     "name": "基础研究",     "color": "#7c5cff"},
{"key": "connected", "name": "智能网联汽车", "color": "#0e9f8a"},
{"key": "security",  "name": "隐私安全",     "color": "#e8890c"},
{"key": "policy",    "name": "政策法规",     "color": "#22a06b"}
```

可选方向池（可增删）：机器人 / 人工智能 / 半导体 / 通信 / 能源 / 安全 / 飞行汽车 / 政策法规 / 智能网联汽车 / 基础研究 / 今日头条 ……

## news（总条数 ≥16；每板块 2-6 条，不必均等）

```json
{
  "module": "connected",
  "title": "标题（含关键数字）",
  "tags": ["#智驾", "#激光雷达"],
  "summary": "事实摘要 ≤200 字，必须含具体数字",
  "opp": "上车机会点一句话（对长安/车企的价值 + 跟踪建议，不写🚗前缀，渲染自动加）",
  "impact": 8,
  "source": "信源名称",
  "grade": "A",
  "sdate": "08-26",
  "url": "https://真实原文链接"
}
```

- `grade`: A=官方发布/顶级期刊；B=权威媒体；C=行业媒体。不许虚标。
- `impact`: 1-10，驱动卡片影响力条。

## insights（恰好 3 条，跨板块提炼当日最强信号）

```json
{"title": "信号标题", "body": "2-3 句摘要", "detail": "4-6 句详细简报，含数字与来源"}
```

## radar（4-6 个领域）

```json
[["智能网联", 92], ["AI算力", 85], ["电池材料", 68], ["安全合规", 74], ["政策", 60], ["机器人", 45]]
```

数值 = 当日该领域信息密度（按真实条目数/权重估算），峰值领域写进 `stats.peak`。

## ops（4-8 条大牛观点）

```json
{
  "stance": "bull",
  "quote": "引文（可浓缩，禁止编造；用 <mark>高亮关键句</mark>）",
  "name": "辛国斌",
  "title": "工业和信息化部 副部长",
  "scene": "国新办发布会",
  "grade": "A",
  "color": "#2f6fed",
  "url": "https://原文链接"
}
```

- stance: bull 看好 / bear 谨慎 / neut 中立
- 发言人资格：院士、部委负责人、车企董事长/CEO/高管、首席科学家、权威机构负责人；
  "业内人士""网友""专家"会被校验脚本拒绝。

{

  "def": "电梯演讲式 3 行定义",

  "sketch": "<svg class=\"sketch\" viewBox=\"0 0 220 90\" width=\"100%\">…手绘风简图…</svg>",
  "steps": ["2023 半固态上车", "2025 舱内方案", "2026.8 Limera", "2027 普及", "2028 纯固态"],

## weekly（七日全景 · 来自 6606 周情报库，强烈推荐）

用 `scripts/fetch_weekly.py` 自动生成（无需手写）：

```json
{
  "source": "6606 周情报库（马良洞见·智驭未来）",
  "week_total": 295,
  "days": [
    {
      "date": "2026-08-21", "weekday": "周五", "count": 40,
      "cats": {"机器人": 22, "人工智能": 5, "其他": 4},
      "picks": [
        {"title": "研究人员开发出全彩近眼显示器…", "url": "https://…", "cat": "机器人"}
      ]
    }
  ],
  "trends": [
    {"cat": "半导体", "summary": "本周半导体领域新品与合作动态不断…"},
    {"cat": "人工智能", "summary": "本周人工智能领域成果丰硕…"}
  ]
}
```

- `days`: 覆盖最近 5-9 天（默认 7 天），按日期升序；`count`=当日 6606 库收录条数，`cats`=当日类目分布，`picks`=当日相关度最高的 3 条精选（带原文）；
- `trends`: 6606 `/api/trends/latest` 的每类目周趋势摘要；
- 渲染为 M5「七日全景」：每日热度条 + 类目分布 + 每日精选可点原文。数据缺失时模板自动隐藏该板块，不会报错。

## stats（页头统计，必须与真实收录一致）

- today = news 条数
- experts = ops 条数；topics = topics 条数
- week = 本周累计（有 weekly 时用 `weekly.week_total` 真实值）
- peak = 雷达峰值领域名
