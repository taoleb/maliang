# 专题深研工作流（topic-workflow.md）

当用户对日报中某条资讯提出"生成专题"（从专题中心复制指令或直接口述），执行本流程。

## 触发识别

- "生成专题：XX（PPT 版…）" → PPT 专题
- "生成专题：XX（HTML 深研长页）" → HTML 专题
- 未指定形式 → 默认 PPT 版（用户是前瞻院情报场景，PPT 为主要交付形态）

## 通用步骤（两种形态都要做）

1. **定位素材**：从当日 `daily-data.json`（或最近一期）找到对应条目，
   取出 title/summary/opp/url 作为种子。
2. **追加定向搜索**（必做，不许只用存量）：至少 3 轮，覆盖
   - 技术原理与最新参数（官方发布/论文）
   - 竞争格局（谁在做、方案对比、供应商）
   - 政策/标准与长安关联（长安现有布局、竞对动态）
   每轮记录真实来源与数字。
3. **结构化**：统一五段式骨架——
   ① 事件/技术是什么（What）② 为什么重要（Why，含量化影响）
   ③ 技术拆解（How，原理/参数/路线对比）④ 竞争格局与供应链
   ⑤ **对长安汽车的含义**（相关度判断 + 布局建议 + 跟踪清单）——这一节是硬要求，必须有。

## PPT 专题（8-12 页，长安模板风）

优先调用用户 PPT 规范（长安模板）：

- 模板基准：`C:\Users\202313680\Desktop\工作文档\模版.pptx`
- 视觉：浅灰底 #F4F5F7 + 深藏青 #12263A + 青绿 #00A38D + 橙 #E87A1E；
  深色顶带页眉、青绿 eyebrow 小标 + 加粗大标题 + 粗黑分隔线、白色卡片 + 彩色顶条、
  深色"核心结论"横条、页脚来源行 + 页码
- 布局：高密度报告风，禁止大面积留白；大数字锚点、对比表、时间轴优先
- 流程：提取素材 → STORY.md + DESIGN.md → 逐页生成 → 校验 → 编译 pptx → 截图抽查
- 若无法走 pptx 编译链路，降级为单文件 HTML 幻灯片（每页 16:9），并在回复中说明

收尾必须有：**相关度矩阵（对长安各业务线）+ 布局建议页 + 跟踪清单**。

## HTML 专题（单文件深蓝科技风长页）

- 结构：头部（专题名 + 日期 + 一句话结论）→ 五段式章节（锚点导航）
  → 数据图表（可用内联 SVG）→ 参考资料列表（全部真实链接）
- 对长安的含义章节用醒目色块（青绿描边卡片），含"建议动作 1-2-3"
- 无外部依赖，present_files 交付

## 质量红线

- 专题中所有数字、引文必须有来源；不确定的标注"待核实"
- 结论落到对长安的含义，不写泛泛而谈的行业综述
- 交付时附上：搜索轮数、新增来源数、与日报条目的关联
