# 技术日报模块规范（modules-spec.md v2.1）

五模块 + 车本位原则。生成时逐项落实。

## 全局原则

1. **信源日 = 发布日前一日**，逐条核实日期，页头显著标注"信源日"；
2. **车本位**：所有板块围绕"能上车/与车相关"选材；
3. **板块数量灵活**：4-8 个自选板块、每板块 2-6 条、总条数≥16，按当日素材分布收敛，不硬凑均等；
4. **每条资讯三件套**：事实摘要（含数字）+【上车机会点】点评 + 可点击原文链接；
5. **观点只收大牛**：具名、有头衔、有原文可查。

## M1 情报信息流

- **AI 智能摘要**：3 张洞察卡，跨板块提炼当日最强信号，点击展开详细简报；
- **板块瀑布流（4-8 板块自选）**：顶部板块筛选条（全部/各板块 + 条数徽章），卡片左上角板块色条；
  卡片含：板块标签 + 技术标签云 → 标题 → 摘要 → 琥珀色【🚗 上车机会点】点评块 →
  底部信源/评级盾标（A绿/B蓝/C灰）/信源日/影响力条/「原文 ↗」（整卡可点击跳转）；
- **情报雷达**：4-6 个领域当日信息密度多边形，数值按真实收录估算。

## M2 大牛观点摘录

- **观点瀑布流**：左竖条标立场（绿=看好/红=谨慎/灰=中立），
  引文内 `<mark>` 高亮 1 处关键句；
- **署名区**：姓名首字头像 + 全名 + 头衔机构 + 发言场景徽章 + 信源评级盾标 + 「原文↗」链接；
- **观点交锋区**：同一议题左右对撞（绿底/红底 + 中央 VS 渐变柱），下方观点时间线；
- **禁入名单**：无具名来源、自媒体臆测、营销话术一律不收。

## M3 技术简介卡片（3-4 张）

- 正面：渐变 Logo 区 + 技术名 + 3 行电梯演讲定义 + 三指标
  （成熟度进度条 / 关注度趋势 / 商业价值评级 S/A/B）；
- 点击翻转 → 背面：手绘风原理简图（viewBox 0 0 220 90）+ 5 节点关键突破时间轴 + 标签云；
- 卡片主题从当日条目中提炼（如：当日刷屏的传感器/芯片/电池技术）。

## M4 专题中心

- 顶部说明条：告知用户"复制指令 → 专题 PPT / HTML 深研"；
- 4-6 张专题卡：编号 + 标题 + 选题理由（琥珀条）+ 3-5 条研究大纲要点 +
  两个按钮「📊 复制 PPT 专题指令」「📄 复制 HTML 专题指令」（点击复制完整指令文案）；
- 指令文案固定格式：
  - `生成专题：<标题>（PPT 版，长安模板风，结论落到对长安的含义）`
  - `生成专题：<标题>（HTML 深研长页）`

## M5 七日全景（来自 6606 周情报库）

- **每日卡片**：近 7 天横向一排，每张卡 = 星期/日期 + 当日收录大数字 + 热度条
  （相对当周最高值）+ Top3 类目徽章 + 每日精选（相关度最高 3 条，可点原文），
  今天卡片高亮描边 + "今日"标签；
- **分类趋势摘要**：6606 `/api/trends/latest` 每类目一段周趋势小结，双列卡片；
- 数据由 `scripts/fetch_weekly.py` 自动生成，缺省时该板块整块隐藏、导航同步隐藏。

## 页头

- 深蓝渐变（#081633→#0d2a5c→#16418f）+ 双色径向光晕；
- 左：卫星 Logo + 标题「技术日报」+ 英文副标；
- 中：发布日期徽章（白底）+ **信源日徽章（"信源日 2026-08-26 · 全部为前一日信源"）**；
- 右：信息源徽章；下排：5 组统计数字（渐变文字）。
